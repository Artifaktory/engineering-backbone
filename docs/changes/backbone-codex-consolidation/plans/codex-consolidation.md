# Codex governance consolidation plan

Task: [BB-CODEX-CONSOLIDATION-002](codex-consolidation-task.json).
The human authorized source analysis, portable integration and publication of one
PR in this repository. Merge, release and downstream writes are separate decisions.

## Deliverables

1. Inventory every file selected by explicit Codex/control-plane path rules from
   complete, pinned Tars and Artifaktory trees. Include supporting Copilot adapters,
   quality, planning, schemas, scripts and tests; distinguish content inspection
   from path-level classification. Compare Artifaktory development staging to main.
2. Integrate portable authority, plan-review, role/scope, finding, remote-review and
   closeout semantics into the common policy and native/generated instructions.
   Keep the three existing native profiles, current schemas and trust tooling.
3. Document per-file decisions, shared sections and safe future project adoption.
   Preserve financial/trading rules, local Publish-Go/signatures/history, commands,
   runner labels and branch strategy in the source projects.
4. Check source and consumers, including actual historical Copier updates preserving
   stronger native files while refreshing shared fragments. Run the trusted-base
   validator and existing security suite before independent Full review.
5. Freeze a commit and patch for two independent reviewers. Record triage, repair
   confirmed findings, and run Delta only for those repairs and direct regressions.
   Publish the reviewed tree, inspect GitHub CI and the Codex provider result.

## Boundaries and evidence

This is a semantic consolidation, not a port of the source orchestrator/control
plane or their authenticated publishing mechanisms. JSON/schema validation does
not enforce prose or authenticate semantic reviews. Runtime client discovery and
repository protections retain their previously documented verification limits.
A complete path inventory is not a claim that every source code/test file received
semantic review. Record exact content-inspected paths separately.
